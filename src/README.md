#------- Fitlog ---------

FitLog is a simple workout library and workout planning web application. Users can browse workouts, view workout details, add exercises to today's plan, save workouts, and track completed exercises.

#------- technologies used ---------

- Next.js
- React
- TypeScript
- HTML
- CSS
- Tailwind CSS
- DaisyUI

#------- Features ---------

- Browse workout library
- View detailed workout information
- Add workouts to today's plan
- Save workouts for later
- Mark workouts as completed
- Sort workouts by duration, calories, and rating
- Responsive design for mobile, tablet, and desktop

#------- API ---------

FitLog uses a workout API to fetch exercise data.
